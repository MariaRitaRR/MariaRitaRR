## 🔮 Projetos Pessoais

### 🎀 Cyberdeck da Barbie

Computador portátil DIY construído sobre um **Raspberry Pi Zero 2W**, alojado dentro de um brinquedo vintage. Rodando **Debian (aarch64)**, com configuração remota via SSH, gerenciamento de energia dedicado e documentação técnica completa de cada etapa do processo.

O cyberdeck roda aplicativos próprios feitos em terminal com [Textual](https://textual.textualize.io/):

- **⏱️ Pomodoro Barbie** — timer de foco com fundo animado — [repositório](https://github.com/MariaRitaRR/timer-pomodoro-barbie)
- **🗂️ FlashCards** — sistema de estudo com pastas e banco SQLite local — [repositório](https://github.com/MariaRitaRR/flashcards)

> Um projeto que reúne sistemas embarcados, Linux, automação e desenvolvimento — do hardware ao software.
